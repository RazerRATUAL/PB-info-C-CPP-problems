# PB-info personal archive

> This repository hosts an extensive portfolio of C-based data structure and algorithm implementations. Sourced predominantly from the educational platform [pbinfo.ro](https://www.pbinfo.ro/), the repository currently encompasses an inventory exceeding **900 resolved problems**, demonstrating diverse approaches to computational logic.

## Overview

This project serves as a comprehensive library of competitive programming solutions. It demonstrates proficiency in problem-solving, algorithm optimization, and manual memory management using C. The solutions cover various domains of computer science, including:

- Fundamental Algorithms & Number Theory
- One and Two-Dimensional Arrays
- String Manipulation
- Recursion and Divide & Conquer
- Sorting and Searching Algorithms

## Language
My preferred language for solving algorithmic problems is C, as it is versatile and gives me a deeper understanding of data structures.

## How to Compile and Run

To test or review any of the solutions on your local machine, you will need a C compiler (such as GCC) installed and preferably a modern IDE for ease of use, such as VS Code.
